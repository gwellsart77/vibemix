## How to ship (for the next chat)
1. `add_repo` gwellsart77/vibemix with push access → clone or push from the container.
2. Bump `VERSION` in `app.py` if the app changed, commit, `git push origin main`. Tag pushes 403
   through the session proxy — don't use them; the Release is cut from the `main` push.
3. Watch `https://api.github.com/repos/gwellsart77/vibemix/actions/runs` (public, curl works;
   the container's `gh` token is invalid). ~6 min. Release updates itself.
4. Mirror changed files to Drive `vibemix/` (Gabe runs the script version from there).
5. Creating anything via the GitHub web UI may be blocked by the classifier → ask Gabe to click.
